See what your AI coder really did.

Agent Receipts reads your AI coding agent's session log and gives you a plain-English receipt: the commands it ran, the files it changed, anything risky, and whether the tests really passed. Free. Offline. No sign-up.

Install in 2 minutes See a live receipt View on GitHub

Why you want this

Catch "tests pass" that isn't true

If the agent says the tests passed but the log says they failed or never ran, you get a warning.

Spot risky actions

Deleted folders, force pushes, curl | sh, edits to secrets and more are flagged, in plain words.

Private by design

Runs on your computer. Nothing is uploaded. Secrets in the log are hidden in the receipt.

Works with your agent

Claude Code, Codex CLI, Gemini CLI and OpenCode. One command, same receipt.

Install

  1. Install Python 3.9 or newer from python.org if you do not have it. Check with:
    python3 --version
  2. Install pipx (it installs command-line tools safely):
    python3 -m pip install --user pipx && python3 -m pipx ensurepath
    Then close and reopen your terminal. On Windows use py instead of python3.
  3. Install Agent Receipts:
    pipx install git+https://github.com/hmzamlla21/agent-reciept.git
  4. Get your first receipt:
    agent-receipts
    Optional: add a /receipt command inside your agent:
    agent-receipts install

Stuck? Run agent-receipts doctor. It checks your setup and tells you what to fix. The full guide is in the README.
